# Mendflow

Актуальная версия проекта в этой папке — это статический фронтенд в `index.html` + PHP API в папке `api/`.

## Что реально используется

- `index.html` — основная страница приложения и активная логика фронтенда
- `style.css` — стили
- `api/db.php` — подключение к БД и базовые helper-функции
- `api/register.php` — регистрация
- `api/login.php` — вход
- `api/posts.php` — получение и создание постов
- `api/like.php` — лайки
- `api/comments.php` — комментарии
- `api/upload.php` — загрузка фото / GIF / видео
- `uploads/` — загруженные файлы
- `install.sql` — схема базы данных
- `diagnostics.html` — страница диагностики API и БД
- `test-api.html` — ручной тест API

## Что загружать на хостинг

В `htdocs` нужно загружать содержимое этой папки:

- `index.html`
- `style.css`
- `api/`
- `uploads/`
- `install.sql`
- `diagnostics.html`
- `test-api.html`

## Настройки InfinityFree

Текущие параметры лежат в `api/db.php`.

Проект поддерживает два варианта:
- значения из переменных окружения `DB_HOST`, `DB_USER`, `DB_PASS`, `DB_NAME`
- fallback на значения, прописанные прямо в `api/db.php`

## Проверка после загрузки

1. Импортируй `install.sql` в MySQL базу.
2. Убедись, что домен указывает на папку `htdocs`.
3. Открой `diagnostics.html`.
4. Проверь регистрацию, вход и создание поста.

## Важно

- `script.js` в текущей папке не является главным runtime-файлом сайта: активная логика сейчас встроена в `index.html`.
- Если будешь продолжать разработку, лучше следующим шагом вынести весь inline-JavaScript из `index.html` в один реальный подключённый файл.
